核心特征

三个特征，重新定义
什么叫一台计算机

这三点不是宣传词，而是这套体系结构在工程上的直接结论。

01

真正的并行计算机系统

不是把任务切碎后在单机里分时排队，而是让计算单元同时、真正地并行推进，并且可以持续横向扩展。

02

计算机即网络，网络即计算机

网络与计算机不再是被连接的两层。你在这一侧看到的是网络，在另一侧看到的就是计算机本身。

03

有心的计算机系统

系统拥有统一的心跳与共识中心，在整体上协同一致，而不只是大量节点的简单堆叠。

体系结构

四层结构，
一台完整的计算机

超导智网把账本、共识与网络收进同一套体系结构里：底层是并行计算， 其上是点对点网络，再往上是共识与账本，最上面才是账户、支付与各类服务。

  • 真正的并行计算机系统，原生支持横向扩展
  • 网络与计算同构，不再有中心化的连接层
  • 共识与账本内建于体系结构，而非外挂中间件
  • 面向 Agent 时代的收付款与结算能力

核心技术

四项底层技术

它们共同支撑起这台计算机的运行方式，也是这套体系结构最难被复制的地方。

01

点对点支付技术

支持微支付，支持批处理，实现了全流程无人化 —— 尤其适合用于 Agent 收付款。

  • 微支付
  • 批处理
  • 全流程无人化
  • Agent 结算
02

抗垄断的共识协议

采用一票否决机制：任何一方都无法在未被认可的情况下单方面改写共识结果。

  • 一票否决
  • 抗垄断
  • 无可单方改写
03

防止财务造假的记账法

把约束写进记账规则本身，在结构上杜绝单方篡改与虚假账目，而不是事后审计。

  • 结构防伪
  • 规则内置
  • 可验证
04

分布式账本

全网共同维护同一份账本，不需要信任任何中心机构，账本本身就是事实来源。

  • 全网共维护
  • 无需信任中心
  • 单一事实来源
核心产品

四款产品，
覆盖账户、结算与防护

它们建立在同一套体系结构之上，可以独立使用，也可以组合成完整的解决方案。

账户

非中心化统一账户系统

基于数字签名技术构建。账户由私钥掌控、归用户所有，无需依赖中心化机构托管，也无法被单方冻结或改写。

结算

可信流量分成服务

基于微支付技术，按真实流量实时计量与结算。每一份贡献都可被度量、可被回报，分成过程公开可查。

防护

抗 DDoS 防护盾服务

借助网络结构本身分散并吸收攻击流量，把防护能力做成网络的固有属性，而不是叠加在边缘的清洗设备。

心跳

数字心脏服务

为系统提供持续、统一的心跳与共识节律，让整台计算机作为一个整体稳定搏动，而不是各自为政的节点集合。
