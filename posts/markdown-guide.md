这一页同时是语法示例和渲染器的自测用例。

## 标题

用 1 到 6 个 `#` 开头：

```
## 二级标题
### 三级标题
```

## 文字样式

**粗体**、*斜体*、~~删除线~~、`行内代码`。

也可以混用：**粗体里的 *斜体***。

## 列表

无序列表：

- 第一项
- 第二项
  - 嵌套一层
  - 再一项
- 第三项

有序列表：

1. 第一步
2. 第二步
3. 第三步

## 引用

> 这是一段引用。
> 可以连着写多行。

## 代码

行内代码写作 `\`code\``。代码块用三个反引号，并在后面标注语言：

```js
function greet(name) {
  return '你好，' + name;
}
console.log(greet('世界'));
```

```bash
git push cdzb168 gh-pages
```

不标语言也可以：

```
没有语法高亮的纯文本块
```

## 表格

| 语法 | 写法 | 说明 |
|---|---|---|
| 粗体 | `**文字**` | 强调 |
| 斜体 | `*文字*` | 轻微强调 |
| 链接 | `[文字](url)` | 站外链接自动新窗口打开 |

## 有意不支持

为了安全，正文里的 HTML 标签不会被解析执行，只会原样显示。比如你写 &lt;script&gt;alert(1)&lt;/script&gt;，页面上看到的就是这串文字本身。
